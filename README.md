# 食材采购验收系统

一个面向食材配送业务的**采购 / 验收 / 对账一体化管理系统**，采用 Rust + Axum + SQLite 构建。

系统采用 **Rust + Axum + SQLite** 实现，服务端按工程化最佳实践组织为多模块结构（入口、API、页面、数据库、认证、工具、模型分层），并内置系统托盘图标，双击即可在本地启动，**完全离线可用**（前端资源全部本地化，无任何 CDN 依赖）。

## 功能特性

### 基础资料管理
- 供应商、采购方、商品（含别名、规格、单位、进价/售价）、仓库管理
- 商品进价/售价自动维护策略：进价随采购单自动更新，售价按加成率自动计算
- 售价尾数规则（仅使用 0/5/6/8/9 尾数）保证定价符合行业习惯
- 价格异常提醒：进价/售价为零、进价高于售价、录入采购单时价格异动、售价低于进价（同商品同基础单位才比较）

### 订单管理
- **采购订单**：创建、编辑、删除、Excel 导入/导出、打印单据、采购单据图片上传
- **销售订单**：创建、编辑、删除、Excel 导入/导出、客户订单/签字验收单图片
- 订单状态机流转：待配单 → 分拣中 → 已分拣 → 配送中 → 已送达 → 已验收 → 已结算
- 由销售订单一键生成各供应商的采购订单（防重复生成保护）
- 配单分拣：支持按采购方、品类、供应商、综合排序等多种分拣视图，并可批量修正数量

### 验收与报销
- 验收单 / 报销单 Excel 导出，支持真实口径与报销口径（合并分摊增项）
- 明细含零金额条目时禁止导出（强制拦截，可按需绕过）
- 导出文件使用订单日期，支持重复标题行与页脚页码

### 查询与分析
- 采购/销售订单查询、采购/销售汇总、商品排行、报销汇总、单据汇总
- **商品进价/售价同期折线走势图**（价格趋势）
- 供应商/采购方往来对账（应收应付）
- 库存查询：库存余额、流水、低库存预警、呆滞库存、进销存汇总
- 收支、毛利明细、品类进销存统计

### 权限与安全（RBAC）
- 细粒度权限点体系：`purchase_order.*`、`sales_order.*`、`query.view`、`manage.*`
- 角色划分：超级管理员 / 管理员 / 供应商 / 采购方 / 普通用户
- **行级数据权限**：供应商账号只能查看/操作自己绑定的供应商单据；采购方账号同理
- **订单状态机约束**：仅待配单（pending）状态的订单允许修改/删除，防止已流转单据被篡改
- **操作审计日志**：所有关键写操作（创建/修改/删除/调价/状态变更等）自动记录操作人、时间与详情
- 密码 bcrypt 加密存储，会话 Cookie 鉴权

### 系统管理
- 用户管理（可绑定供应商/采购方实现行级权限）
- 系统参数配置、数据库备份 / 恢复 / 完整性检查
- 异常数据自查与清理工具

## 快速开始

### 环境要求
- Rust 工具链（stable）

### 运行

```bash
cargo run
```

启动后会自动打开浏览器访问 <http://127.0.0.1:3000>（监听 `0.0.0.0:3000`）。

### 构建发布版

```bash
cargo build --release
```

产物位于 `target/release/food_accept_single.exe`，可独立分发（连同 `static/` 资源与 `food_accept_v3.db`）。

## 默认账号

系统初始化时会自动创建超级管理员账号，请登录后在「用户管理」中修改密码并创建业务账号。

## 权限体系说明

权限按「权限点」粒度控制，而非整页开关：

- **super_admin / admin**：全部业务权限与系统管理权限
- **supplier（供应商）**：采购单的创建/修改/取消、销售单与查询的只读
- **purchaser（采购方）**：销售单的创建/修改/审核/调价/取消、采购单与查询的只读
- **user（普通用户）**：仅查询

行级数据权限通过用户绑定 `supplier_id` / `purchaser_id` 实现，未绑定的业务账号只能看到自己的数据；所有变更均写入 `operation_log` 审计表，可按时间回溯追责。

## 数据库说明

- 主数据库 `food_accept_v3.db` 纳入版本控制（数据库结构随功能变更同步入库）
- 运行时产生的上传图片（`uploads/`）、调试日志不入库
- 提供备份 / 恢复功能，备份文件默认存放在 `backups/`
